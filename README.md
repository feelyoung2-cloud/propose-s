> **“살기 좋은 과천시, 우리 손으로 제안해요!”**  
> 초등학교 4학년 2학기 사회과 **‘지역 사회의 발전과 문제 해결’** 단원을 위한 실시간 인터랙티브 웹앱입니다.  
> 빌드 도구(npm build) 없이 순수 HTML/CSS/JavaScript(ES 모듈)와 Firebase(Firestore + Hosting)만으로 즉시 작동 및 무료 배포가 가능합니다.

## 👩‍🏫 초보 교사를 위한 설치부터 무료 배포까지 12단계 가이드

Firebase는 구글에서 제공하는 무료 클라우드 서비스입니다. 초등학생 1개 학급(20~30명) 수업에 드는 비용은 **완전 무료($0)** 범위 내에서 여유롭게 운영할 수 있습니다.

### 1단계: Firebase 프로젝트 만들기
1. [Firebase 콘솔(console.firebase.google.com)](https://console.firebase.google.com/)에 접속하여 구글 계정으로 로그인합니다.
2. **[프로젝트 추가]** 버튼을 클릭합니다.
3. 프로젝트 이름에 원하는 이름(예: `gwacheon-class4`)을 입력하고 [계속]을 누릅니다.
4. Google 애널리틱스는 필요하지 않으므로 체크를 해제하고 **[프로젝트 만들기]**를 완료합니다.

### 2단계: 웹 앱 등록하기
1. 프로젝트 개요 화면 중앙에서 웹 아이콘(**`</>`**)을 클릭합니다.
2. 앱 닉네임에 `과천시수업앱`을 적고 **[앱 등록]** 버튼을 누릅니다.
3. 화면에 나오는 `firebaseConfig` 객체 코드를 확인합니다.

### 3단계: Firestore Database 만들기
1. 왼쪽 메뉴에서 **빌드 > Firestore Database**를 선택하고 **[데이터베이스 만들기]**를 누릅니다.
2. 데이터베이스 ID는 기본값 `(default)`로 둡니다.
3. 위치(Location)는 가장 가까운 서울 리전 **`asia-northeast3 (Seoul)`**을 선택합니다.
4. 보안 규칙 시작 모드는 **[테스트 모드에서 시작]**을 선택하고 [만들기]를 누릅니다. (추후 배포 시 `firestore.rules`가 자동 적용됩니다.)

### 4단계: `public/firebase-config.js`에 설정값 넣기
웹앱 폴더 안의 `public/firebase-config.js` 파일을 메모장이나 코드 편집기로 열고, 2단계에서 복사한 값으로 채워 넣습니다:

```javascript
export const firebaseConfig = {
  apiKey: "AIzaSy...",
  authDomain: "gwacheon-class4.firebaseapp.com",
  projectId: "gwacheon-class4",
  storageBucket: "gwacheon-class4.appspot.com",
  messagingSenderId: "123456789...",
  appId: "1:123456789:web:abcdef..."
};
```
> 💡 **꿀팁:** 이 설정값을 아직 입력하지 않은 상태에서도 웹 브라우저에서 열면 **체험용 로컬 시뮬레이션 모드**로 작동하여 수업 전 기능을 미리 둘러볼 수 있습니다.

### 5단계: Node.js 및 Firebase CLI 설치하기
컴퓨터에 [Node.js 공식 홈페이지(nodejs.org)](https://nodejs.org/)에서 LTS 버전을 설치한 뒤, 터미널(명령 프롬프트)을 열고 아래 명령어로 도구를 설치합니다:
```bash
npm install -g firebase-tools
```

### 6단계: Firebase 로그인
터미널에서 로그인 명령어를 입력하여 브라우저에서 본인의 구글 계정을 인증합니다:
```bash
firebase login
```

### 7단계: 프로젝트 연결 (`firebase use --add`)
프로젝트 폴더 위치에서 명령어를 실행하고 1단계에서 만든 프로젝트를 선택한 뒤 별칭(예: `default`)을 입력합니다:
```bash
firebase use --add
```

### 8단계: 로컬에서 동작 확인하기
아래 명령어를 실행하면 컴퓨터에서 바로 열어볼 수 있습니다:
```bash
firebase serve
```
웹 브라우저에서 `http://localhost:5000`으로 접속하여 화면이 정상적으로 열리는지 확인합니다.

### 9단계: 인터넷에 배포하기 (`firebase deploy`)
터미널에서 다음 명령어를 실행하면 Hosting과 Firestore 보안 규칙이 전 세계 어디서든 접속 가능한 웹사이트로 배포됩니다:
```bash
firebase deploy
```
배포가 끝나면 터미널에 `Hosting URL: https://gwacheon-class4.web.app` 주소가 나타납니다!

### 10단계: 학생용 링크와 교사용 링크 확인하기
학교 스마트보드나 태블릿에서 사용할 주소는 다음과 같습니다:

| 화면 이름 | URL 경로 | 용도 |
| :--- | :--- | :--- |
| **수업 메인 허브** | `https://[내프로젝트].web.app/index.html` | 5개 화면 바로가기 메뉴 |
| **화면1: 도입 설문** | `https://[내프로젝트].web.app/student.html` | 학생 태블릿용 불편함 조사 |
| **화면2: TV 설문 결과** | `https://[내프로젝트].web.app/teacher.html` | 교실 TV용 실시간 차트 & 히트맵 |
| **화면3: 제안하는 글쓰기** | `https://[내프로젝트].web.app/write.html` | 학생 태블릿용 모둠별 편지 작성 |
| **화면4: 학생 공감 게시판** | `https://[내프로젝트].web.app/board.html` | 학생 태블릿용 공감(❤️) & 댓글 |
| **화면5: 교사용 순위 발표** | `https://[내프로젝트].web.app/board.html?role=teacher` | 교실 TV용 공감 베스트 1·2위 발표 |

> 📱 **수업 팁:** `student.html` 주소를 [네이버 QR코드]나 구글 크롬의 [페이지 QR 코드 생성] 기능으로 만들어 교실 화면에 띄우면 학생들이 태블릿 카메라로 3초 만에 접속할 수 있습니다.

### 11단계: 수업 전 실시간 연결 사전 점검
1. 교사용 PC에서 `teacher.html`을 엽니다.
2. 스마트폰이나 다른 탭에서 `student.html`을 열어 설문을 하나 제출해 봅니다.
3. 교사용 화면의 그래프와 숫자가 **새로고침 없이 실시간으로 1 증가**하는지 확인합니다.
4. `write.html`에서 제안 글을 올리고 `board.html`에 즉시 카드가 뜨는지 확인합니다.
5. 테스트가 끝나면 `teacher.html` 상단의 **[🗑️ 응답 모두 지우기]** 버튼을 눌러 테스트 데이터를 비웁니다.

### 12단계: 수업 후 데이터 삭제 및 서비스 정리
- **데이터 비우기:** 다음 수업을 위해 `teacher.html`의 [응답 모두 지우기]를 실행하거나, Firebase 콘솔 > Firestore에서 `responses`와 `proposals` 컬렉션을 삭제합니다.
- **배포 중지(필요 시):** 더 이상 웹사이트를 운영하지 않을 경우 터미널에서 `firebase hosting:disable`을 실행하면 서비스가 안전하게 비활성화됩니다.

## 🔒 로그인 없는 공개 웹앱의 특성과 보안 한계 안내

이 앱은 초등학교 교실에서 **학생들의 구글 로그인 번거로움과 개인정보 수집을 없애기 위해** 링크 접속 방식으로 설계되었습니다. 따라서 기술적으로 다음과 같은 한계가 존재하며, 이는 교사의 따뜻한 수업 관찰과 지도로 보완됩니다.

1. **교사용 URL(`?role=teacher`)의 성격:**
   - 이 주소는 별도의 교사용 비밀번호나 계정 권한이 아닌, 교실 대형 TV 화면에 최적화된 발표 뷰를 띄우기 위한 화면 분기 주소입니다.
   - 학생들이 주소창에 `?role=teacher`를 임의로 입력해 들어가지 않도록 수업 전 링크를 명확히 안내해 주세요.

2. **비속어(욕설) 필터링:**
   - `app.js`에 초등학생 수준의 비속어 목록(`BAD_WORDS`)이 포함되어 실시간으로 입력을 차단합니다.
   - 단, 의도적으로 자모를 분리하거나 신조어·변형된 비속어는 클라이언트 필터를 우회할 수 있습니다. 수업 전 “친구들과 함께 읽는 고운 말 쓰기” 인성 교육을 병행해 주세요.

3. **공감 중복 방지 (기기별 1회):**
   - 브라우저의 `localStorage`를 통해 같은 태블릿에서는 한 제안에 1번만 공감할 수 있도록 제한되어 있습니다.
   - 브라우저 시크릿 창을 열거나 저장소를 초기화하면 우회될 수 있으므로, “서로를 존중하며 1인 1표 지키기” 규칙을 지도해 주세요.

4. **Firestore 보안 규칙 (`firestore.rules`):**
   - 수업 진행을 위해 읽기와 생성은 누구나 가능하도록 허용되어 있습니다.
   - 단, 제안 문서의 수정은 `likes`가 정확히 1 증가하는 것 외의 악의적인 위·변조를 원천 차단하도록 엄격히 검증됩니다.
